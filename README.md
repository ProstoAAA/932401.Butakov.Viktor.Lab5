# 932401.Butakov.Viktor.Lab5
Персональная веб-страница «О себе» (с поддержкой JavaScript)

Учебный проект (Лабораторная работа №5, Вариант 1: «Студент-разработчик») — интерактивная веб-страница с информацией о навыках, проектах, галереей, формой обратной связи и скриптом на JavaScript для динамического управления проектами, переключения тем оформления и сохранения состояния страницы в localStorage.

Особенности проекта:

    Поиск и манипуляции с DOM: использование методов getElementById, querySelector и querySelectorAll для работы с элементами страницы, управления классами, текстовым содержимым и узлами DOM без перезагрузки.

    Динамическое управление проектами: создание новых карточек проектов через document.createElement с заполнением данных из prompt и добавлением в DOM через appendChild; безопасное удаление последнего элемента с помощью метода remove() и выводом системных уведомлений alert и console.log.

    Переключение тем оформления: кнопка смены темы, переключающая классы theme-light и theme-dark на элементе body и динамически меняющая CSS-переменные для цветовой схемы.

    Скрытие и показ блоков: функционал сворачивания и разворачивания контейнера с проектами с помощью добавления или удаления класса hidden.

    Обработка ошибок: строгая проверка существования элементов в DOM через условные операторы if перед вызовом функций и логирование ошибок в console.error.

    Сохранение состояния в localStorage: автоматическое сохранение выбранной темы оформления, состояния видимости блоков и актуального списка карточек проектов при добавлении или удалении; полное восстановление данных при перезагрузке страницы.

    Сетка навыков (Grid): оформление списка навыков карточками с плавным увеличением (transform: scale(1.05)), мягкой тенью и декоративным бейджем «Top skill».

    Галерея скриншотов: адаптивная Grid-сетка скриншотов с подписями в тегах figure и figcaption.

    Адаптивность: корректное отображение на мобильных устройствах, планшетах и десктопах (1, 2 и 3 колонки) благодаря meta viewport и медиа-запросам.
